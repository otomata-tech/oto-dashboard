#
# Ce fichier existe pour une seule raison : un témoin qui naît rouge n'est jamais lu.
# Au premier passage, `npm run schema:check` trouvait DIX divergences réelles. Sur un job
# hebdomadaire, personne n'aurait plus jamais distingué la onzième. Cette liste est donc
# la base du témoin : le contrôle échoue sur ce qui n'y figure PAS.
#
# ⚠️ Elle ne doit que DÉCROÎTRE.
#
#   - Un écart nouveau, absent d'ici → le job échoue. C'est le but : on le règle, ou
#     quelqu'un DÉCIDE de l'inscrire ici, en connaissance de cause et par un commit qui
#     dit pourquoi. Rien ne s'ajoute tout seul : une base qui grossit d'elle-même serait
#     pire que pas de témoin — elle transformerait le contrôle en registre de ce qu'on
#     tolère.
#   - Une ligne d'ici qui n'est PLUS un écart → le job échoue aussi, et demande de la
#     retirer. Sans quoi une dette réglée dort ici pour toujours, et la liste ment sur ce
#     qu'elle coûte encore. Retirer la ligne est le geste qui clôt la dette.
#
# Format : <sens> <clé>. Les commentaires et les lignes vides sont ignorés.
#
#   lue-non-servie   le dashboard lit cet attribut, la plateforme ne le connaît pas :
#                    depuis le 01/10/2026 elle le REFUSE à la pose et au patch (le
#                    vocabulaire des schémas est fermé) — un écran qui l'écrit échoue.
#   servie-non-lue   la plateforme sert cet attribut comme lu par le front, aucun accès
#                    n'existe ici : elle promet un lecteur qui n'existe pas.
#
